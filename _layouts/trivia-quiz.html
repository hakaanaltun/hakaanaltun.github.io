--- layout: default --- {%- comment -%} One quiz page. Everything a quiz needs is here, so a quiz's own file under trivia// is front matter and nothing else: page.quiz names the bank in _data/quizzes/, and the card copy comes from the entry in _data/trivia.yml. Rounds are not written anywhere. Each question carries a category, the bank is stored grouped by category, and js/trivia.js turns a run of one category into a round — so the round count below and the rounds a reader plays are the same fact read twice, never two numbers to keep in step. A bank with no categories still works; it falls back to rounds of ten. {%- endcomment -%} {%- assign quiz = site.data.quizzes[page.quiz] -%} {%- assign rounds = quiz | map: "category" | compact | uniq -%} {%- for entry in site.data.trivia -%} {%- if entry.slug == page.quiz -%}{%- assign meta = entry -%}{%- endif -%} {%- endfor -%}
